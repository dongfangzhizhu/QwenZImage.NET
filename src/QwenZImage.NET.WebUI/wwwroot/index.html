Reference backend — not real inference. The loaded native library is the deterministic test implementation: it emits pseudo-random pixels (noise). Steps / seed / guidance only drive the progress bar — no model is loaded and no diffusion happens. To get real images you must do two things: (1) build the CUDA engine with scripts\build-native-cuda.bat / scripts/build-native-cuda.sh, and (2) select that build — building alone is not enough, because the app loads the bundled reference library by default. Set QZI_NATIVE_LIBRARY=<repo>/artifacts/native/Windows-AMD64-cuda/QwenZImageNative.dll (Linux: Linux-x86_64-cuda/libQwenZImageNative.so) and point QwenZImage.config.json at your model packs. Easiest: run scripts/start-webui-cuda.ps1 / scripts/start-webui-cuda.sh — it selects the CUDA build and refuses to serve generation jobs if the noise backend is still loaded. See docs/WEBUI.md.

Margins enlarge the output canvas (width / height stay the final size); the reference is fitted into the remaining inner rectangle. Every margin must be a multiple of 32 px and leave at least a 32×32 source. LanPaint needs a painted mask and cannot be combined with margins.

ControlNet Union · guide preprocessing

Inpaint mode: this control image is paired with the brush mask above. The job is posted as model=zimage-inpaint (or a control request carrying mask_image); both rasters are required.

The WebUI runs the estimator, not the native library. canny / scribble / gray / depth work out of the box with dependency-free operators; pose and learned depth / contour use WanGP ONNX assets from preprocess_dir in QwenZImage.config.json (or QZI_PREPROCESS_DIR). Only the resulting guide is posted to /api/jobs.

Upload a photo (or an already-formatted guide). The selected preprocessing mode turns it into a Z-Image ControlNet guide; choose raw to keep the pixels exactly as supplied.

Real weights required: configure the Z-Image Turbo Fun ControlNet Union weights via zimage_control_dir in QwenZImage.config.json (or QZI_ZIMAGE_CONTROL_DIR). The bundled reference backend only performs a deterministic byte comparison and emits noise — it is not real ControlNet inference.

Jobs run strictly one at a time on the native engine. This console uses no Go process, no HTTP hop to a sidecar — only the C ABI via .NET.

Configuration file — preview / apply

The WebUI can merge the six resolved model directories into the current platform section of QwenZImage.config.json. Only those keys are touched, a timestamped .bak.* copy is made first, and the write is atomic. Restart the WebUI afterwards — the native engine reads its config once at startup. Environment variables (QZI_*) and --models take precedence over the file.
